# Tic-Tac-Toe-Game

## Project Overview

Tic-Tac-Toe-Game is a simple and interactive browser-based game designed for two players. The project focuses on clean UI design, responsive layout, and smooth user interaction using core web technologies without any external framework.

The game allows two players to take turns placing **X** and **O** on a 3x3 board. It automatically detects the winner, handles draw situations, and allows users to restart the game easily.

## Features

- Two-player Tic Tac Toe gameplay
- Clean neumorphic user interface
- Responsive design for desktop, tablet, and mobile screens
- Automatic winner detection
- Draw detection
- Restart/reset game functionality
- Simple and user-friendly layout
- Built with vanilla JavaScript, HTML, and CSS
- Deployed live using Vercel

## Technologies Used

- HTML5
- CSS3

- Vercel

## How to Play

1. Open the live demo link.
2. Player 1 uses **X**.
3. Player 2 uses **O**.
4. Players take turns clicking empty cells.
5. The first player to align three marks horizontally, vertically, or diagonally wins.
6. If all cells are filled and there is no winner, the game ends in a draw.
7. Use the restart button to play again.
